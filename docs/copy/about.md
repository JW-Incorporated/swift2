## About this project

The Vault is a time machine through Taylor Swift's eras — pick a moment,
any month since 2006, and see what was actually happening then: the
outfits, the tours, the songs taking shape.

It's built by fans, for fans, because a Pinterest board of "1989 era
aesthetic" isn't quite the same as being able to actually walk through it.
Dated Vault items are sourced and linked back to where they came from —
we're not in the business of guessing.

This is an independent, unofficial fan project. See [Unofficial /
disclaimer](./unofficial.md) for the full details.
