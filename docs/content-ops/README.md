# Content Ops Standards

These are **proposed standards (v1), pending review** — each formalizes an
open GitHub ticket into a concrete, adoptable rule for authoring Vault
content, grounded in the marketing framework docs and decisions already on
record; comment or file a ticket against any of them to change what's here
rather than silently drifting from it in practice:
[`depth-rubric.md`](./depth-rubric.md) sets the 3-tier curated-depth rubric,
authoring order, and public-launch content bar (#15);
[`editorial-voice-and-pipeline.md`](./editorial-voice-and-pipeline.md)
defines the fan-editor third-person voice, sourcing bar, and the
Claude-drafts → Codex-reviews → human-spot-checks authoring pipeline (#17);
[`song-annotation-standard.md`](./song-annotation-standard.md) governs
source-gated song meaning/background/Easter-egg annotation for songs that
already have a `month_item` (#33); and
[`theory-weaving.md`](./theory-weaving.md) covers weaving sourced,
content-only fan theories into a song's existing content with a hard
relationships/private-life exclusion (#35).
