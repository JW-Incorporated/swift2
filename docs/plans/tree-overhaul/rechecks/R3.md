## Judgment

Everything R3 was written to test got built and runs: per-post metrics are
fetched daily, the scorecard renders, the ladder standing block is live, A4
sampling produces scored reports, e2e is green un-quarantined. The one FAIL is
about *memory*, not metrics.

1. **Lessons memory has one rule, not three (FAIL).** Most likely cause: the
   lessons ledger only grows on a Monday weekly-plan run, and of the last two
   Mondays one produced nothing new and one (10-05) failed before delivery.
   The W41 ledger already holds an un-distilled founder reason from 10-06
   (*"Don't show me posts that I can't reply to"* — a Reddit-target
   selection rule, nothing to do with photos). Smallest fix: land the brief
   delivery path (#4889) so the Monday run reaches its distillation step, and
   have the next Monday run distil that W41 reason into L002.
2. **Rejection rate collapsed to 0% for the right reason.** The photo famine
   that caused every rejection in this plan's history is over — the 10-01
   guardrails ruling made uncredited photos usable, and #5352 reports a
   healthy inventory ("140 never-used"). This is a real win, but it rests on
   4 posts; it is not yet a trend.
3. **Publication has stalled for six days** (newest item in `social/posted/`
   is 2026-10-02; `social/queue/` was empty at the start of today's drafter
   run). #5352 flags this itself and attributes it to approval quiet, not a
   code fault — the 10-05 `launch:community-engine` day-0 and the 10-06
   easter-eggs slot both never shipped, and the arc is now deferred.
4. **output-sampling's 10-05 failure has a concrete cause.** `gh run view
   37355399932 --log-failed` → `[routine-output-sample] error: Command failed:
   gh search issues --repo JW-Incorporated/swift2 Tier-2: Nils — site walk
   --limit 100 --json number,state,createdAt`. The routine label is
   interpolated into the search query unquoted, so the colon and em-dash break
   it. One-line fix: quote the query argument in the sampler.
