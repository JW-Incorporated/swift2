## The authority boundary (established before any change)

AI Dev OS v3.2 installs its authority at the **user** level, not the repo level:

| Surface | Location | Effect |
|---|---|---|
| Lead-behavior instructions | `~/.claude/CLAUDE.md` (marker-delimited) | Routing, task registration, Fable decisions, billing guardrails |
| Task-registration hook | `~/.claude/settings.json` → `UserPromptSubmit` → `src/tasks/hook.mjs` | Every prompt, every repo |
| MCP server | `ai-dev-os` (global `mcpServers`) | `create_task`, `delegate_task`, `delegate_review`, `record_outcome`, `human_required`, … |
| Routing / model / review / supervisor / billing policy | `ai-dev-os/policy/routing-policy.yaml` | Authoritative for tunable values |
| **Repo-level share** | **`.claude/rules/ai-team-coordination.md` only** | `REPO-001`…`REPO-007` |

`ai-dev team-bootstrap <repo>` writes **exactly one file** and, by its own
source contract, "NEVER touches any other file in the target repo (especially
CLAUDE.md / other .claude contents)." **Retiring kit-v3 is therefore a manual
editorial job, not something the bootstrap does.** That is the substance of
this migration.

## Conflicts discovered

1. **`REPO-006` vs STATE.md / PLAN.md.** The load-bearing conflict. kit-v3 made
   a single mutable root file authoritative shared state; `REPO-006` forbids
   exactly that. Resolved by demoting STATE.md to an archive plus read-only
   derivatives, with GitHub as the shared plane.
2. **Two `UserPromptSubmit` hooks.** `triage.sh` (repo) and AI Dev OS's
   `src/tasks/hook.mjs` (global) both fire on every prompt, asserting different
   routing authorities. Resolved by retiring `triage.sh`.
3. **Model pin conflict.** Repo `settings.json` pinned `"opus"`; global pins
   `claude-fable-5[1m]`; routing policy assigns `claude` as `lead_integrator`
   and `fable` as `reversible_decision_authority`. Repo pin retired.
4. **Pre-existing, NOT created by this migration: Workflow rule 3 vs Joey's
   ruling.** `CLAUDE.md` rule 3 makes Codex cross-review mandatory and says the
   in-house `reviewer` "does NOT satisfy" it. `STATE.md` § Merge authorization
   records Joey overriding this: *"Codex is OUT by his explicit ruling… a
   `reviewer` agent is the sanctioned substitute. Do not re-raise."* The two
   root documents contradicted each other. **Surfaced, not silently resolved.**
5. **~30 worktrees live *inside* the repo** at `.claude/worktrees/`, plus ~60
   more under temp. Housekeeping debt predating this migration; flagged, not
   touched.
6. **Plaintext `VERCEL_TOKEN` in `~/.claude/settings.json`.** Outside this
   repo's scope; flagged to the owner, not modified.
