## Tried and skipped — no working Taylor-specific feed found (2026-08-23)

Full context in `supabase/migrations/20260823010000_news_sources_seed_wave2.sql`'s
header comment; summary:

- **People, Entertainment Tonight** — Dotdash/Meredith tag pages carry no
  per-tag RSS link anymore; the only discoverable feed on People's tag page
  was a generic "Celebrity" feed, not Taylor-specific. ET's `/rss` directory
  lists only category feeds (news/style/music/…), no per-celebrity tag.
- **Vogue, Elle, Harper's Bazaar** — no `/tag/taylor-swift/feed/` endpoint
  (404) on any of the three. Elle/Harper's Bazaar (both Hearst) expose
  `/rss/search.xml?q=…` but it returns 0 items regardless of the query
  parameter tried (`q`, `s`, `query`, `term`, `keyword`, `keywords`) — the
  endpoint appears to no longer honor a query at all.
- **The Tennessean** — no tag/topic RSS discoverable; `/topic/taylor-swift/`
  404s and the search-results page carries no `<link type="application/rss+xml">`.
- **Kansas City Star** — Akamai bot mitigation (TLS renegotiation loop, then
  a silent connection drop) blocks every request from this environment,
  including the plain homepage; not fetchable here regardless of feed path.
- **Pitchfork** — no `/tag/taylor-swift/feed/`, artist-scoped RSS, or
  equivalent found; only whole-site news RSS (`/rss/news/`) exists.

`packages/shared/src/news/outlet-tiers.ts`'s domain->tier map still lists all
of the above as `established` — Google News can surface them even without a
direct feed, and a resolved redirect landing on one of these domains should
still earn the tier it deserves (proposal §4.1.2).
